This folder contains Box 3, i.e. taking a tasked commercial SAR image and running flood mapping algorithms upon it. There are several .py files that help to extract metadata from the image, prepare an image to work in HYDRAFloods, and a module that attempts to geocode raw range-azimuth imagery. There is also a folder called notebooks that contains various tests of ICEYE imagery using HYDRAFloods. ICEYE imagery must be uploaded to Google Earth Engine in order to work with HYDRAFloods.
